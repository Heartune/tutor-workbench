# 函舟工作台 · tutor-workbench

## 这是什么

一个高中数学老师给自己做的软件，用来把手头的教辅书变成印着自己品牌的讲义 PDF。

做家教要给学生发讲义。常见做法是复印教辅，或者从题库里拼一份 Word 打印出来，效果跟复印店的卷子没区别，家长看不出你在这上面花了功夫。这个项目做的事是：把《5 年高考 3 年模拟》（高中生常用的一套教辅，下面简称 53）北京版数学里的题目和讲解拆出来存好，之后老师在网页上下一个单——"这次讲导数的综合应用，给中等偏上的高三学生，要 8 道例题"——由 AI 照着做出一份排版讲究、带自己 logo 和配色的讲义。同一份稿子印两个版本：发给学生的只有题目和空白，老师自己留的那份多出完整解析和解题技巧。

现在只做讲义这一件事。做视频、管学生这些以后再说。

完整的设计过程和每个决定背后的理由，见 [`../教培工作台-思路整理.md`](../教培工作台-思路整理.md)；五个人的分工见 [`docs/分工.md`](docs/分工.md)。

## 架构与技术栈

这套东西没有数据库，也不用部署到服务器上，只在老师自己的电脑上跑。所有数据就是硬盘上的文件夹和文件：知识点目录是一个 YAML 文本文件，每份讲义是一个文件夹，里面装着这次的下单信息、稿子和印出来的 PDF。想知道三个月前那份讲义是怎么做出来的，打开那个文件夹看一眼就知道；想备份就是复制文件夹。因为只有一个人用，账号、权限、多人协作这些统统不需要，省下来的复杂度很可观。

界面是一个网页，用 Vue 3 加 TypeScript 写，Vite 打包，只在本机打开。网页背后是一个 Node.js 小程序（Express 框架），大概一百行，只干四件事：列出有哪些文件、读写文件、接收上传的图片、把 PDF 送给网页显示。看 PDF 直接用浏览器自带的阅读器，不额外做。真正的重活由几个 Python 脚本承担，需要时由那个小程序启动：从 Word 里抠出题目和公式、从扫描版 PDF 里认字、把稿子编译成 PDF。讲义排版用 LaTeX（一套专门排数学公式的系统），编译器用电脑上已经装好的 MiKTeX。

网页不直接跟 AI 对话。它只负责生成一张"任务单"文件，上面写清楚这次讲哪个知识点、用哪些题、给什么水平的学生看；AI 那边有一份固定的作业流程说明书，读这张任务单干活。好处是以后想改 AI 的干活方式不用动网页，而且任务单能存档、能复制——下次做类似的讲义，复制上次的任务单改两行就行。

所有素材都挂在一棵知识点树上，分三层：专题（导数及其应用）、小节（导数的综合应用）、题型标签（隐零点、极值点偏移）。前两层照着 53 的目录建，每份素材都必须挂上；第三层是随手能加的标签，一道题可以同时属于好几个。这棵树是把讲义、题目、图片、以后的视频串到一起的共同坐标，没有它，这些东西之间就没法互相找到。

## 核心功能

**把教辅拆成能反复用的素材。** 53 的每个小节配了 Word 和 PDF 两种资料，这两种得分开对付。Word 里的文字和公式都是现成的，用程序原样转成 LaTeX，图片从 Word 压缩包里直接抠出来，全程不让 AI 碰题目原文——这条是刻意定死的：题目抄错一个指数、出处标错，印在发给家长的讲义上，你没办法一道道核对。AI 只负责挑题、排顺序、套模板、插入老师自己的内容。

精讲册 PDF 是扫描件，整页都是图片，没有文字层，只能靠工具认字。认出来的东西分四类处理：讲解文字交给 AI 理解意思后用老师自己的话重写，这是讲义能和原书拉开差距的地方；公式和插图直接用认出来的结果；表格由脚本转换，AI 只调样式、不碰数据。用到哪一节才处理哪一节，处理完存进素材库，下次直接读。不一开始就把整本书跑一遍，因为那样处理的大部分章节你根本用不上。

**做讲义的过程里有两个必须人工点头的地方。** 第一个是大纲：AI 先只交一份几十行的大纲，说明分几节、每节讲什么、挑了哪些题、题目出自哪里，三十秒能看完。选错题、难度跑偏这类最贵的错误全发生在这一层，在大纲上改是改两行字，等稿子和插图都做完再发现就得整份重来。第二个是印出来的 PDF：翻一遍，哪节不满意就只重做那一节，别的不动——稿子是按节拆成多个文件的，所以能做到局部返工。

**一份稿子出两个 PDF。** 稿子最上面有一个开关，打开印教师版：题目、完整解析、方法总结、老师自己的解题技巧，每段内容旁边还标着出自原书哪一页，方便抽查。关掉印学生版：只有题目和留白。这样上课时老师看得到解析而学生看不到，学生版还能顺手发到自媒体上。这个开关必须一开始就设计进去，等攒了几十份讲义再补是灾难。

**排版是刻意投入的地方。** 内容大部分来自 53，辨识度不可能来自内容本身，只能来自排版：统一的封面、logo 和字体，七种颜色的方框各自对应一种用途——红色是易错提醒，绿色是方法总结，蓝色是知识拓展，读者靠颜色就知道这一段是干什么的。品牌相关的设置全部集中在一个文件里，以后换名字、换配色只改那一个文件。

**讲义管理是白送的。** 每份讲义就是一个文件夹，里面有一张任务单，网页上的列表只是把所有任务单扫一遍显示出来，不用另做一套管理功能。

---

**使用边界**：内容来源以 53 北京版数学的配套资源为主，对其做结构化整理与二次编辑，用于个人教学与个人品牌展示。原书著作权归权利人所有；讲义中的讲解文字为基于原书要点的重写稿，题目与解析保留原始题源标注。对外公开发布的只有学生版（题目与留白），教师版仅供本人使用。
